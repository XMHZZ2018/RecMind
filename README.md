# RecMind

One of the first LLM-based agentic system for recommendation that combines tool use, memory, and self-inspiring planning for zero-shot and few-shot recommendation tasks.

## Paper

**Title:** RecMind: Large Language Model Powered Agent For Recommendation

**Conference:** Findings of the Association for Computational Linguistics: NAACL 2024

**Paper:** https://aclanthology.org/2024.findings-naacl.271/

## Repository Note

This repository is maintained for the RecMind project webpage.

Due to company policy, the source code associated with this paper cannot be open-sourced at this time.
